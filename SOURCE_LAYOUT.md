## Path rules

- PHP includes use `__DIR__`; config/storage use `dirname(__DIR__, 2)`.
- No runtime file hard-codes `C:\xampp`, `htdocs`, or `laragon`.
- Browser URLs use `base_path()` / `base_url()` from `SCRIPT_NAME`.
- `config.local.php` is generated by the installer or `install/install.php`.
- `storage/barcode_secret.key` is generated on first run and must not be shipped.

## Packaging

The distribution ZIP adds:

```
PENSI_EVENTPRO_Setup.exe    one-click installer (embedded app/)
samples/                    real e-ticket JPG + PDF
git/                        full Git bundle
START_HERE.txt              teacher/friend quick start
VERSION, CHECKSUMS.sha256   metadata
```

`docs/schema.sql` from older versions is intentionally removed; the single
source of truth is `database/schema.sql`.
